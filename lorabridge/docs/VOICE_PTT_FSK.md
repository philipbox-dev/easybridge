# FSK PTT-рация (экспериментальный дизайн, V2.7+)

## Статус
**Не реализовано** — дизайн и план. Голосовые *сообщения* (запись → отправка)
уже работают в V2.6 на любом железе, включая E220. Реалтайм-рация требует
FSK-режима, который есть только у SPI-радио.

## Матрица возможностей

| Радио | GFSK | Макс. битрейт | Реалтайм голос |
|---|---|---|---|
| E220-400T30D (UART) | нет доступа | 62.5к LoRa | ❌ только сообщения |
| E22-400M33S (SX1268) | да | 300 кбит/с | ✅ возможен |
| T3 / SX1276 | да | 300 кбит/с | ✅ возможен |

## Дизайн

- **Кодек**: Codec2 3200 бит/с (или 1600 при плохом канале). Кодирует ТЕЛЕФОН
  (JNI-библиотека codec2), устройство — прозрачный транспорт. Микрофона на
  платах нет — телефон = гарнитура.
- **Транспорт**: телефон → BLE (кадры Codec2 по 20 мс, пачками по 5 = 100 мс)
  → ESP → GFSK 9.6 кбит/с пакетами по ~60 байт (~150 мс буфер).
- **Ожидаемая задержка**: BLE ~30-60 мс + буферизация 150 мс + эфир ~60 мс
  ≈ **0.3-0.5 с** — приемлемо для PTT.
- **Полудуплекс**: захват канала пакетом PTT_START (LoRa-режим), затем
  переключение обеих сторон в GFSK на время сессии, PTT_END → обратно в LoRa.
  Таймаут 2 с без кадров = принудительный возврат в LoRa.
- **SX126x**: `SetPacketType(0x00)` = GFSK; модуляция: 9.6 кбит/с,
  fdev 25 кГц, BT 0.5, RX BW 117 кГц. Синхрослово 4 байта, CRC16, variable len.
- **SX127x**: OpMode LoRa-бит=0 → FSK; RegBitrate 9.6k, RegFdev 25 кГц.

## Почему не сейчас
1. Нет E22-400M33S/T3 на столе у агента — драйвер sx126x.c и так не прогонялся
   на железе; городить поверх него FSK вслепую = двойной риск.
2. Codec2 JNI — отдельная сборка нативной библиотеки в Android-проект.
3. Сначала стоит обкатать голосовые сообщения V2.6 — они покрывают 90%
   сценария «сказал — услышали».

## Порядок работ, когда дойдут руки
1. Bring-up sx126x.c на E22-400M33S (LoRa-режим, интероп с E220).
2. GFSK-режим точка-точка между двумя T3 (у них проще всего: 2 шт, 868 МГц).
3. Codec2 JNI в EasyLink + loopback-тест телефон→ESP→эфир→ESP→телефон.
4. PTT UI (зажать-говорить) + захват/освобождение канала.
