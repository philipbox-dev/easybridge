⚡ EasyBridge Flasher

Подключите плату по USB и нажмите кнопку. Работает в Chrome / Edge (WebSerial), страница должна быть открыта по http://localhost или HTTPS.

Загружаю профили…

Профили и таблицы пинов сгенерированы из main/hwcfg.c скриптом tools/gen_profiles.py — это тот же список, который знает прошивка.
Прошивка одна на чип: какое именно радио и дисплей припаяны, задаётся после прошивки из приложения EasyLink (Настройки → Железо → профиль). Там же задаётся имя пользователя.
Локальный запуск: python -m http.server -d tools/flasher/web 8000
