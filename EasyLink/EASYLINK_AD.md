# EasyLink + EasyBridge — связь там, где её нет

Горы. Лес. Тайга. Ноль палок сотовой связи. **А вы — на связи.**

**EasyBridge** — карманная LoRa-радиостанция, которая превращает ваш телефон в мессенджер, рацию и SOS-маяк **без сотовой сети, без интернета, без SIM и без абонентской платы**. Просто достал, включил — и говори.

---

## 📡 Связь

- **Сообщения на километры без вышек** — общий канал, личные чаты, группы
- Галочки доставки: отправлено ✓ / доставлено ✓✓ — как в обычном мессенджере
- **Голосовые сообщения** до 8 секунд — прямо по радиоэфиру
- **Фото по эфиру** — сжатые снимки долетают туда, где нет ни одной сети
- **Звонки-рация в реальном времени**: держи кнопку — говори. Три режима: ДАЛЬНОБОЙ / СТАНДАРТ / HD. Адресный вызов конкретному человеку, экран «ожидание ответа», история звонков, свои мелодии
- Быстрые фразы одним тапом: «Да», «Иду к тебе», «Помоги!», «Жди меня»
- Недоставленное **досылается само**, как только связь появилась
- **Mesh-ретрансляция**: устройства передают сообщения по цепочке до 5 прыжков

## 🆘 Безопасность в походе

- **Кнопка SOS**: тройная передача на максимальной дальности, у всей группы — сирена, пробивающая беззвучный режим, имя и координаты пострадавшего
- **SOS-эхо**: устройства сами повторяют чужой сигнал бедствия через 30 и 90 секунд — тревогу услышат даже те, кто был вне зоны в момент отправки
- **«Все живы?»** — один тап, и видно, кто из группы ответил «я в порядке»
- **Аварийный dead-man таймер**: не отметился вовремя — авто-SOS с последней локацией. Создан для соло-выходов
- **Режим маяка «потерялся»**: частая передача позиции, напарник наводится по компас-стрелке прямо на тебя

## 🗺 Навигация

- **Живая карта группы**: все участники и их перемещения за сутки
- **Офлайн-карты**: скачал район дома — в лесу карта работает без интернета
- **Режим «Радар»**: свои на пустом поле вокруг тебя, крутится по компасу, дистанция и направление до каждого — работает вообще без карт
- **Маршрут до узла**: линия «я → напарник» с расстоянием
- **Запись трека**: маршрут, километраж, экспорт GPX
- Автомаячок позиции с умным интервалом (стоишь — бережёт батарею)
- Высота и давление по барометру телефона, тренд погоды

## 🔒 Приватность

- Шифрование всего эфира **AES-128** одним паролем сети
- Плюс отдельные ключи **AES-256** на каждый чат и группу
- **Обмен контактами и ключами по QR** за секунду — никакого ручного ввода
- Чёрный список узлов

## ✨ Комфорт

- Красивое современное приложение, **русский и английский**, тёмная тема
- **Тихий режим для охоты**: всё молчит, кроме сирены SOS
- **Итоги дня**: пройдено, набор высоты, сообщения, доставка — поделись одним тапом
- **Батареи всей группы** на одном экране
- Виджет на рабочий стол, уведомления с ответом из шторки
- Поиск по переписке, закреплённые сообщения
- **Автоподключение**: открыл приложение — связь уже есть
- **Замер дальности**: график «расстояние ↔ сигнал» для поиска предела связи
- Инженерная консоль и полный лог сессии для диагностики
- Встроенная справка: как работает LoRa, советы по дальности

## ⚙️ Характеристики

| | |
|---|---|
| **Радио** | LoRa 433/868 МГц; дальность — километры, при прямой видимости и хорошей антенне — десятки километров |
| **Мощность** | 21–30 dBm (до 1 Вт), настраивается из приложения; высокая мощность — в экспертном режиме под ответственность пользователя |
| **Скорость** | два пресета с синхронным переключением всей сети |
| **Звонки и фото** | GFSK 2.4–50 кбит/с (платы SX127x) |
| **Автономность** | до суток и более активной работы — реальный полевой тест: 5 часов связи с геомаячком = 13% батареи |
| **Лимиты** | текст до ~1200 байт, голос до 8 с, фото ≤ 9 КБ (3 прохода избыточности) |
| **Телефон** | Bluetooth LE, связь живёт в фоне; Android 10+, APK ~60 МБ |
| **Платы** | LilyGO T3 (SX1276 — звонки, фото, экран), ESP32-S3/C6 + E220, ESP32-S3 + E22 |
| **Прошивка** | обновляется по USB через веб-флешер за минуту |
