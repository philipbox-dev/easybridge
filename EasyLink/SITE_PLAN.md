## Когда будет сервер — порядок действий (~30 минут)

1. **Решить, какой домен**: поддомен на meetjimproviz.ru (если есть доступ к DNS), новый домен, или пока «серый» вариант. HTTPS обязателен — WebSerial-флешер без него не работает, «просто по IP» не вариант.
2. DNS A-запись → IP сервера.
3. `rsync tools/site/ → /srv/easylink/` на сервере.
4. Поставить Caddy, вписать домен в Caddyfile, reload — TLS он получит сам.
5. Проверка: лендинг открывается, APK качается и ставится, флешер видит плату по USB из Chrome.

## Решения, которые надо принять (обсудим когда вернёшься)

- **Домен**: что вписываем? Это единственный блокер.
- **Release-подпись APK**: сейчас debug-ключ. До публичной раздачи надо сгенерить keystore (5 минут) и собрать `assembleRelease` — иначе у скачавших не встанут обновления из другого источника. Keystore потом НЕ ТЕРЯТЬ (это и есть «личность» приложения).
- **Открытость флешера**: страница прошивки доступна всем или прячем за простую ссылку-секрет? (Твой moat — приложение, но прошивку с сайта сможет скачать любой.)

## Следующие фазы (не сейчас)

1. **`version.json`** на сайте (`{"app":"1.7.5","fw":"2.9.6"}`) + проверка в приложении → плашка «есть обновление».
2. **QR-серия/пломба устройств** — то, что ты обдумывал для цеха: страница `/verify?sn=...`, база серийников. Первый реальный бэкенд; до него всё статика.
3. **Заказы/витрина** — когда решите с продажами (пары, комплекты).
4. Аналитика без Google (self-hosted umami/plausible), если захочется считать посетителей.
