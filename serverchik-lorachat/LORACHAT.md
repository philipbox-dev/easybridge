# LoRa-чат — веб-зеркало LoRa-сети

Модуль сайта meetjimproviz.ru, живущий по адресу `/lora-chat/`. Часть
экосистемы **EasyBridge / EasyLink** (прошивка: `~/esp/lorabridge`).

Идея: сообщения, голос и фото ходят по LoRa между устройствами, а
сервер держит их веб-копию. Кто сидит за компом — пишет из браузера, и
его сообщение уходит адресату либо по интернету (если тот тоже в вебе),
либо по эфиру через телефон-шлюз. **Веб не заменяет LoRa** — это второй
маршрут, который дешевле и шире, когда интернет есть.

## Файлы

| Файл | Что внутри |
|---|---|
| `lorachat.py` | Модели, роуты, WebSocket, доставка. Точка входа — `create_lorachat_blueprint()` |
| `lorachat_bus.py` | Реестр живых соединений и **выбор маршрута** веб/эфир |
| `lorachat_call.py` | Звонки: арбитраж эфира («слово»), формат аудиокадров |
| `lorachat_expr.py` | Безопасные выражения для виджетов датчиков |
| `lorachat_dev.py` | Автономный запуск без `app.py` — для разработки и тестов |
| `static/lorachat/call.js` | Микрофон, кодеки и воспроизведение в браузере |
| `templates/lorachat_*.html` | Список сетей, админка, вход, комната чата |
| `run_lorachat_tests.sh` | Прогон 106 тестов в своём venv |

В `app.py` от модуля — 19 строк: подъём `flask_sock.Sock` и
`register_blueprint`. Так его можно будет унести на отдельный сервер,
если сеть перерастёт сайт.

## Роли

- **хост** — зарегистрированный пользователь сайта. Создаёт сеть,
  заводит участников, настраивает виджеты и кнопки;
- **участник** — логин, пароль и персональная ссылка
  `/lora-chat/<uid>/chat`. Аккаунт на сайте ему не нужен. Ссылка сама по
  себе не пропуск: она попадёт в историю браузера и в чужой скриншот,
  поэтому пароль обязателен;
- **устройство** — телефон с EasyLink или вкладка браузера. Телефон
  вдобавок работает **шлюзом**: выносит сообщения в эфир и
  перекодирует звук во время звонка.

## Как выбирается маршрут

Получатель в вебе → интернет. Нет → эфир через чей-нибудь телефон.
Шлюзом предпочитается телефон самого отправителя: он рядом с человеком,
его `node_id` стоит в сообщении, лишнего прыжка по мешу не будет.

SOS уходит **обоими** маршрутами всегда: цена ложного дубля несравнима
с ценой недоставленного SOS.

Если шлюза нет, отправитель узнаёт об этом сразу (`lora_blocked`), а в
браузере появляется баннер. Принять сообщение и молча не доставить —
худший из вариантов.

Пакеты из эфира дедуплицируются по `(сеть, node_id, packet_id)`: один
пакет слышат все телефоны в радиусе, и без этого каждое сообщение
двоилось бы по числу шлюзов.

## Хранение

Текст — навсегда, он почти ничего не весит. Место занимают медиа:
квота 2 ГБ на сеть, срок жизни 30 дней, файл до 50 МБ, дедупликация по
SHA-256 (пересланное фото не ест квоту дважды). История показаний
датчиков живёт 60 дней.

Текст сообщений и файлы шифруются на диске AES-GCM ключом на сеть
(ключ — в `instance/lorachat_key`). Сервер читать может: нужны превью,
поиск и восстановление доступа хостом. Смысл шифрования другой —
унесённый бэкап или снятый диск не читаются как открытая книга.

## Звонки

Веб-участники слышат друг друга свободно; тем, кого в вебе нет, голос
уходит по FSK через шлюз. **Сервер не трогает звук** — он раздаёт кадры,
не зная, что внутри. Перекодирует телефон: у Android уже есть Opus и
AMR-NB в `MediaCodec`, а ffmpeg на веб-сервере пришлось бы кормить на
каждом звонке.

Эфир полудуплексный, поэтому у радио-плеча есть «слово»: в вебе можно
перебивать, в эфир уйдёт речь одного. Слово берётся неявно первым же
кадром и держится ещё 1.2 с после последнего — иначе пауза между
словами отдавала бы микрофон соседу.

## Устройства и виджеты

Датчики и реле объявляют себя сами; заводить их руками не нужно.
Виджет строится из манифеста, а хост может добавить вычисляемые строки
на мини-языке (`lorachat_expr.py`).

Выражения **не приходят из эфира** и не являются кодом: только
арифметика над показаниями, без вызовов, атрибутов, импортов и циклов.
Почему так — в `~/esp/lorabridge/docs/DEVICES.md`.

## Разработка

```bash
./run_lorachat_tests.sh              # 106 тестов, своё окружение
python lorachat_dev.py --seed        # http://127.0.0.1:5055/lora-chat/
```

`lorachat_dev.py` поднимает модуль без `app.py`: трогать живой сайт
ради проверки формы логина незачем. `--seed` заводит тестовую сеть с
участниками Philip / Misha / Roma (пароль `test1234`) — та самая тройка
из сценария «двое в вебе, третий в эфире».

## Установка на сервере

Разово, перед первым деплоем:

```bash
pip install flask-sock cryptography
```

Без `flask-sock` чат поднимется, но без реалтайма — клиент откатится на
`/api/history` и `/api/send`. Без `cryptography` не поднимется вовсе: на
нём шифрование.

После выкладки — перезапуск gunicorn. WebSocket идёт через `gthread` и
Caddy; апгрейд Caddy проксирует сам.
